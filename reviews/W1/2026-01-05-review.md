## Review - 오늘 한 일 & 배운 점 (1월 5일)

### 1. 5Vs of Big Data

- 빅데이터의 5가지 특징인 Volume, Velocity, Variety, Veracity, Value에 대해 배웠다.
  - Volume: 데이터의 양이 매우 크다.
  - Velocity: 데이터가 생성되고 처리되는 속도가 매우 빠르다.
  - Variety: 데이터의 형태가 다양하다.
  - Veracity: 데이터의 신뢰성이 중요하다. (정확하지 않은 데이터는 분석에 큰 영향을 미칠 수 있다.)
    - 이 Veracity를 누가 보장할 것인가에 대한 고민이 필요하다. 엔지니어 or 데이터 사이언티스트?
  - Value: 데이터에서 가치를 추출하는 것이 중요하다.

### 2. Problem Decomposition

- Task Parallelism과 Data Parallelism에 대해 배웠다.
  - Task Parallelism: 서로 다른 작업을 병렬로 처리하는 것
  - Data Parallelism: 동일한 작업을 여러 데이터에 대해 병렬로 처리하는 것

### 3. High Availability & Fault Tolerance

- 시스템의 고가용성과 장애 허용성에 대해 배웠다.
  - High Availability: 시스템이 항상 사용 가능하도록 하는 것
  - Fault Tolerance: 시스템이 장애가 발생해도 정상적으로 동작하도록 하는 것

### 4. Docker

- Docker는 가벼운 것 뿐만 아니라, 금액의 관점에서도 효율적이다.
  - Hypervisor 기반의 가상 머신은 Guest OS가 필요하고, 각 OS별로 라이선스 비용이 발생할 수 있다.
  - 반면, Docker는 Host OS 위에서 컨테이너가 동작하기 때문에, OS 라이선스 비용이 발생하지 않는다.
